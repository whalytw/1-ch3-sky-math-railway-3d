# 天空函數鐵道 3D — Sky Math Railway

高中數學第一冊 CH3-2〈簡單多項式函數及其圖形〉的三人獨立 3D 教學遊戲。**車內跟隨鏡頭更新版（V0.2）**。

## 立即開始

1. 解壓縮後，執行 `python -m http.server 8000`（在專案資料夾內）。
2. 開啟 `http://localhost:8000`，即可測試。不必安裝 npm、Node.js 套件或下載 3D 引擎。
3. 或上傳本資料夾全部檔案到 GitHub Repository，至 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)**，即可發布。若喜歡 GitHub Actions，也附有可用的 `.github/workflows/pages.yml`。
4. GitHub Pages 地址形式為 `https://你的帳號.github.io/sky-math-railway-3d/`（若 repository 名稱相同）。

> 如果直接雙擊 `index.html`（`file://`），瀏覽器可能禁止 ES Modules 載入。請使用上述本機網頁伺服器或 GitHub Pages。

## 教師設定

- 右上角「教師控制中心」，依序切換遊戲 A/B/C。
- 八座島嶼各有獨立開關與 1～5 星設定，預設三區都只開前四座島嶼（**總共4關，共6星等**）。
- 「簡單4島／中等6島／進階8島」可單獨套用至目前選中的區域，也可複製到其他兩區。
- 各區題目依課本順序；每島一題；同島同星使用相同題型規則、不同數字。不同星等或關卡配置時，兩區不保證同題型。
- 任一區學生開始後會取得設定快照。教師調整設定只影響下一位學生。
- 答錯／逾時立即顯示數學步驟與 SVG 圖示，該題零分；閱讀後按「修復軌道並繼續」。
- 第一次正確答題：100基本分＋0～40時間獎勵－每張求救卡20分，最低0分。
- 完成八個（或教師實際啟用的）關卡後獨立結算、獨立換人。可 CSV 匯出成績。

## 技術

- `src/math.js`：資料驅動的題庫產生、驗證、教學解說；**所有參數與答案都會重新檢查**。
- `src/renderer.js`：**原生 WebGL2** 的真實 3D 渲染，單一 WebGL Context + 三個 `viewport/scissor`，程序生成低面數島嶼、軌道、礦車及機關；免下載外部 3D 套件。這是第一版為了保證 ZIP 解壓後可直接發布而改用的輕量引擎；未來可換 Three.js 而保留題庫及遊戲邏輯。
- `src/app.js`：三位獨立遊戲狀態、教師設定、觸控、題目 UI、計分、暫存及 CSV。
- `styles.css`：三區布局和低寬度互動控制介面。
- `tests/math.test.mjs`：每島每星 180 題，合計 **7,200** 組答案與特殊情況自動驗證。執行 `node tests/math.test.mjs`。

## 瀏覽器需求與效能

建議 Chrome、Edge 或其他支援 WebGL2 的現代瀏覽器。若裝置未啟用 WebGL2，會自動降級至 2D 相容景觀，仍可進行全部數學操作。以 Surface Pro 8 為目標裝置，但**尚未在真正的 Surface Pro 8 或 IFP8653＋AirSync／Touchback 實機測試**。目標是三人模式約 30 FPS，教師可切換低／標準／高或自動畫質。數學操作由 HTML 控制，以 Pointer Events 相容的原生 `input`／`button` 實作，與 3D 渲染獨立。

目前場景是程式生成的卡通 3D，未包含高精度 Blender 美術模型、後端雲端排行榜及教師身份驗證；這些屬後續可擴充功能。

## 出題來源

參考本次上傳《高中數學(1) CH3-2 簡單多項式函數及其圖形》PDF 第108–129頁的內容，依次涵蓋對稱、中點、函數值、一次函數、二次函數圖形及平移、配方、判別式、極值、營收與矩形面積最佳化。題目數值和文字為程式原創產生，不將課本原頁面上傳至網站。

## 提醒

目前儲存使用瀏覽器 `localStorage`；不同電腦不會自動同步。重新整理頁面後可從各區首頁按「恢復進度」，但進行中的題目會從該關重新計時。CSV 成績可在教師控制中心匯出。

## 目前版本的界線

這是一個可以玩完全部八種數學機關的 **V0.1 原型**，並非已在 Surface Pro 8 的投放環境實測過的正式教室版本。不同星等已提供部分不同係數範圍與多步驟題型，但後續還可以進一步增加高星題庫的多樣性、美術場景細節與完整動畫。


## V0.2 乘坐礦車的沉浸式視角

- **真正修改了 WebGL 攝影機**，從上一版固定側面的模型展示，改成攝影機隨礦車移動，**預設為主角坐在礦車內的第三人稱追隨鏡頭**，並可切換第一人稱車內視角。
- 鐵軌向遠方延伸，路線包含空中的彎道、起伏、護欄、枕木、橋墩與經過的裝飾拱門；數學區間仍以正確的函數圖形產生軌道。
- 加入坐在車內的卡通主角、車輪與車身；第一人稱模式另有車頭護欄；行駛時 3D 視窗自動變大，數學作答時停車，保留足夠空間操作題目。
- 進島行駛約 5.8 秒，答對後沿修復軌道前進約 7.2 秒，可按「略過行駛」縮短全班輪替時間。
- WebGL2 不可用時，Canvas 2D 相容畫面也改用前方透視軌道（此模式不是 3D，使用硬體加速的 Chrome/Edge 才會啟動真正 WebGL2）。
- 原先三區獨立選島、星等、題目、詳解、成績與「總共 n 關，共 m 星等」都保留。
- **尚未在 Surface Pro 8 + IFP8653/AirSync 實機驗證**，此階段屬可玩原型，不等同 Rail in the Air 的商用品質模型與物理系統。

### 鏡頭控制與本版測試

- 預設為「◉ 主角跟隨鏡頭」，畫面會看見主角坐在礦車裡；按「切換：車內視角」切換第一人稱，三區可獨立切換。
- 行車畫面會擴大；若需縮短課堂輪替時間，可以按「略過行駛 »」，不影響題目、分數或島嶼進度。

- `node tests/camera.test.mjs`：120 個幾何、車體和相機路徑檢查，涵蓋八島與三個遊戲區。
