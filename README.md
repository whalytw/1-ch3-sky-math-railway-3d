# 天空函數鐵道 3D — 三人共圖競速 V1.0

更新日期：2026-10-24。這是由 V0.3 大改版的完整遊戲，不需要另外合併舊版檔案。

## 開啟遊戲

### GitHub Pages

解壓縮後，把本資料夾內的 `index.html`、`styles.css`、`src/`、`assets/` 等檔案一起上傳或覆蓋到原本的 GitHub 專案，維持原有 GitHub Pages 發布方式。請勿只更新 index.html。上傳後以 Ctrl+F5 重新載入，確認頁首顯示「三人競速 V1.0」。

### 本機測試

在本資料夾開啟終端機，執行 `python -m http.server 8000`，再以 Chrome 或 Edge 開啟 `http://localhost:8000`。若 Windows 使用 Python Launcher，也可執行 `py -m http.server 8000`。

本遊戲沒有外部 CDN、npm 執行依賴、雲端服務或額外模型下載。由於採 ES Modules，請使用本機網頁伺服器或 GitHub Pages；直接雙擊 index.html 可能被瀏覽器限制。

## 上課操作

1. 右上角「統一設定」調整啟用題型、各題型難度和作答秒數，一次套用三區。也可以用「一鍵統一難度」把全部題型設成相同星等。
2. 首頁填入三位學生的座號，按「三人同時出發」。每組使用新的隨機地圖；「換一張地圖」可先預覽另一組風景。
3. 三秒倒數後出現 GO，三台礦車一起出發。碼表從 GO 開始。
4. 各區獨立回答題目，礦車持續行駛。三人全部抵達後，可查看本場解題紀錄，或按「下一組三人出發」。
5. 右上角有全螢幕、音效與暫停。全螢幕 API 若受瀏覽器限制，可按 F11。

每場約 3 分 50 秒～5 分 03 秒，依答題速度與加速累積而定。此版以全長 5 公里完賽，題數依實際作答速度而變動。

## 比賽規則

| 項目 | V1.0 行為 |
|---|---|
| 地圖 | 同一張程序生成的 3D 地圖，三台車共用沿途風景及物件；各自使用第三人稱跟隨鏡頭 |
| 路線 | 三條不同轉彎與起伏的路線；依實際曲線弧長各為 5,000 公尺；前、後半各為 2,500 公尺 |
| 起終點 | 三車同處並列起跑、同處並列抵達；起點與終點各有跨越三軌的拱門 |
| 風景 | 森林、丘陵、雪地、火山、田園、沙漠、鄉下、湖畔；每場抽取兩種不同風景 |
| 進度 | 各區上方 0%～100% 數線；自己為大亮點及百分比，另外兩車為小亮點 |
| 起步 | 0 km/h 出發，5 秒內升至基準 60 km/h |
| 首題 | GO 後第 8 秒出現；作答時不會停車 |
| 答對 | 把實際剩餘作答秒數立即累加到加速秒數；保留小數，畫面顯示至 0.1 秒 |
| 加速 | 加速秒數大於 0 時，每秒增加 2 km/h，最多 80 km/h；由 60 到 80 共 10 秒 |
| 減速 | 加速秒數歸零後，每秒減少 2 km/h，最低回到 60 km/h |
| 題目間隔 | 答對、答錯或逾時後都等 5 秒，自動出下一題 |
| 求救卡 | 每題可用一次，顯示解題提示並立即扣 10 秒；最少扣至 0，扣至 0 當下判定逾時 |
| 中點動作 | 跑到 50% 時，主角舉一隻手後放下 |
| 超車動作 | 從後方超越原先領先者時，主角跳起、轉一圈再坐回車內，播放歡呼音效；被超車者顯示 !!，持續 2 秒 |
| 判定領先 | 依各自從起點累計的沿軌道距離判定，與畫面上的前後位置無關；起跑同距離不觸發假超車 |
| 完賽 | 依實際跨過 5,000 公尺的時間判定名次；同一更新畫格內抵達也以跨線時間排序 |

## 原題庫與答題方式

保留 V0.3 的 `src/math.js` 題庫及數學計算，不改動題型、數字難度與正確答案模型：

- 鏡像之島：對稱與中點。
- 函數能源站：函數值、代入與展開。
- 斜坡峽谷：斜率與截距。
- 拋物線工廠：開口、平移與參數。
- 配方研究所：配方與頂點式。
- 判別式迷宮：與 x 軸的交點個數。
- 極值山谷：二次函數極值、區間極值。
- 最佳化天空城：圍欄面積與營收最佳化。

預設啟用前四類，沿用原版各類星等；每題預設 45 秒，可指定 10～180 秒，或選擇原版各題型的 35～100 秒。啟用的題型按順序輪替，直到抵達終點。同一題次三人的題型規則相同，題目數字各自產生。

選擇題先點選選項，再按確認。數字、坐標、係數、最佳化等題目使用黑底半透明小鍵盤；點選欄位後輸入，→ 切換欄位，± 切換正負號，⌫ 刪除，✓ 送出。鍵盤不會在每次輸入時重建。第一下數字會取代欄位的預設值，後續數字接續輸入。數字題仍保留即時面積／營收讀值。原先依函數作圖的展示軌道改為競速路線，題目本身維持原題庫。

題目顯示在各區上方黑底半透明卡片，鍵盤位於右下角，跟隨鏡頭把角色保留在左下方；跳起動畫也有預留範圍。較長的題目卡片可在卡片內捲動。答題後的 5 秒可展開詳解與函數圖，完賽後也可逐題回看。

## 三人觸控與 IFP8653

- 遊戲按鍵使用 Pointer Events，按下立即更新，接受第二、第三個非主要觸點。
- 依 pointerId 管理觸點、按鍵與取消事件，不使用跨玩家共用的防連按鎖。
- 數字鍵至少 44 CSS 像素；快速交錯連按、長按不重複、後續 click 去重、鍵盤與輔助工具的 click 都有處理。
- 遊戲按鍵停用頁面捲動與縮放手勢；題目卡片需要捲動的部分仍可捲動。
- 統一設定內可開啟觸控接收計數，查看三區接收次數、目前觸點與最多同時觸點。此計數不影響成績。
- 進入設定／解題紀錄時，全場暫停；切到背景分頁也會暫停，返回後按「繼續競速」。

程式測試包含三個重疊觸點及快速交錯輸入，尚未在真正的 IFP8653 與 AirSync Touchback 上實測。若觸點根本沒有傳入瀏覽器，網頁無法補回該次觸控；可用接收計數比較有線連接與 AirSync 的差異。

## Surface Pro 8 效能設定

預設自動畫質，採低多邊形場景、單一 WebGL2 context 與三個 viewport。三區共用同一份場景緩衝；只繪製鄰近路段，礦車與角色使用可重複繪製的模型。沒有即時陰影、材質貼圖、大型外部 3D 引擎或大量粒子。

標準模式目標 30 FPS，畫面像素比例與裝置像素比有上限；連續低幀率會自動降至省電畫質。高畫質可嘗試 60 FPS。實際幀率取決於 Surface 的電源模式、瀏覽器硬體加速及投放方式，並未在你的 Surface Pro 8 上實測保證。

若體感不順，可先在統一設定選「省電／低畫質」。瀏覽器無 WebGL2 時會切至 2D 相容景觀，規則與共用座標相同；畫面底部會明確標示。相容模式的風景與動畫較簡化。

## 成績與設定

設定與完賽紀錄保存在同一瀏覽器的 localStorage，最多保留最近 200 場。統一設定內可匯出 CSV，每題含座號、隊伍、名次、完賽時間、題型、星等、作答、正解、求救與獲得的加速秒數。不同電腦或不同瀏覽器不會自動同步。

本場中途重新整理會回到首頁；V1.0 以三人同場競速取代舊版各區的中途恢復與獨立換人。教師在比賽中更改難度與時間，只影響下一場；畫質與音效即時生效。
