# V1.6.1 驗證範圍 — 2026-10-27

## 程式測試

`npm test` 的 13 組測試全數通過：

- 題庫 7,200 題、常數 ±1 顯示及 900 組參數題。
- 三級加速、答對排程、1.5 秒升速、消退速度、五秒題間隔、求救卡、15 秒衝線滑行與個人紀錄獨立運作。
- 3,060 組路線／鏡頭取樣、18,036 組地面檢查、39,690 組地面網格淨空及 17,248 組觀眾腳下定位。
- 三個重疊觸點、非主要觸點、90 次快速交錯按鍵、長按、click 去重、取消與舊式觸控後備。
- 28 種點綴、開關、密度限制、共用世界事件與設定遷移。
- 17,280 個快速飛行取樣畫面、23 次共享事件：有界位移、方向與實際速度一致、世界座標不隨玩家搬移、單個風箏／紙飛機與永遠不可達的浮島。
- 九種四視角角色的橫移／迎面／飛離選圖；立體紙飛機在傾斜時機頭仍對準航向。
- 連續局部動畫、固定翼根、每像素單一姿勢取樣、附件旋轉、粒子循環淡出與滾動中心。
- 礦車及飛行物陰影、鳥群個別投影、實際地面／橋面接收位置、高度相關偏移、夜景光暈、遠處天體與陰影品質設定。
- 固定 WebGL 網格、共用 VAO、貼圖快取、背景 Worker、有限頻率陰影緩衝更新及完整資源釋放。

## 本次修正的驗證

- 浮島在固定航向下，對 5 種前進距離、4 種速度、3 種俯仰的畫面中心與包圍尺寸逐一比對，完全一致；左／右轉時移動方向符合預期。
- 場景只產生一個天空浮島；不進入路邊或伴飛池，尺寸控制在小型遠景範圍。
- 綿羊每跳起點、最高點、終點與中間點符合寬扁拋物線；以 60 Hz 取樣 40 秒核對連續向前與透明重設，腿部動畫與跳躍同步。

## 實際渲染管線

使用遊戲 `SharedRenderer` 真正產生的鏡頭、模型、貼圖與繪圖呼叫，在 Mesa OpenGL ES 3 管線重播日景、夜景和橋梁場景；生產版著色器編譯／連結成功，所有繪圖呼叫無 GL 錯誤。也以原本的 CanvasFallbackRenderer 輸出相同三種測試場景。

`docs/render-day-v1.6.1.png`、`render-night-v1.6.1.png`、`render-bridge-v1.6.1.png` 為這些固定測試位置的實際輸出，未疊題目 UI。圖中刻意同時擺放代表性物件，並非正式遊玩時的隨機出場密度。它們不是 AI 生成的整張遊戲示意圖。

另以 transform feedback 核對 540 組 CPU／GPU 動畫頂點變形，最大差異約 1.15×10⁻⁷。可重跑工具在 `tests/visual/`。

## 尚未驗證的環境

本輪沒有可用的瀏覽器執行檔，沒有完成 V1.6.1 的真實瀏覽器互動驗證。渲染重播與 Canvas 輸出不等同完整瀏覽器測試。

未在真正的 Surface Pro 8、IFP8653 或 AirSync Touchback 上量測幀率及實體多點觸控。60 Hz 程式取樣不代表硬體保證達到 60 FPS，也不能保證 Touchback 會傳送所有觸點。首次上課前宜確認三人同按與快速輸入，並依設備表現調整陰影、畫質與點綴密度。
