# V1.4 驗證範圍

- `npm test` 包含原題庫、賽程、世界、觸控、渲染狀態、背景 Worker、前版設定與地形、持續伴飛。
- 伴飛以每秒 60 次取樣，涵蓋女巫、鳥、鯨魚、火龍、英雄、飛機與水母，檢查朝向、位置、尺寸、透明度和身分持續。
- `actual-3d-witch.png` 與 `actual-3d-birds.png` 使用本版實際 JavaScript 產生的地形、角色、材質、UV 與世界矩陣，透過 OpenGL ES 3 渲染。這些是場景檢查圖，未疊上答題介面，也不是生成的遊戲示意圖。
- 瀏覽器測試在 1280×720 與 2560×1440 的畫面尺寸載入全部素材，並確認數字鍵盤作答與加速。該測試瀏覽器沒有 WebGL2，UI 測試使用 2D 相容模式；3D 材質另以上述實際 OpenGL ES 3 核對。
- 未在真正的 Surface Pro 8、IFP8653 或 AirSync Touchback 上量測，不宣稱已驗證固定 60 FPS 或實體觸控硬體相容性。
