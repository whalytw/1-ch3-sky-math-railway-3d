# V1.5 驗證範圍 — 2026-10-25

## 已完成

- `npm test` 全套通過：題庫、賽程、世界、觸控、渲染狀態、背景 Worker、設定、地形淨空、持續伴飛與動畫。
- 7,200 道題目自動驗算，另有 900 組參數公式；保留三級加速、五秒題間隔、求救卡、衝線滑行及個人紀錄互不暫停的測試。
- 三個重疊觸點、非主要觸點、90 次交錯快速按鍵、長按、click 去重與取消後繼續操作。
- 25 種點綴、四段密度、開關、安全範圍；4,785 個出現位置、18,036 組貼地檢查、39,690 組地面網格淨空、17,248 組觀眾腳下檢查。
- 七類伴飛角色以 60 Hz 取樣，共 30,598 個畫面、34 次出場、18 次完整退場；檢查朝向、位置、尺寸、透明度及角色身分連續性。
- 15 種美術的週期連續性與局部變形；鳥、蝴蝶、火龍翅根固定、單一貼圖取樣，13 張獨立 PNG 皆有 Alpha。
- 真正的 OpenGL ES 3 編譯／連結遊戲著色器；240 幀、15 種動畫都有可量測的畫面變化，無 GL 錯誤。另以 450 組頂點與左右朝向比對 CPU 與 GPU 的變形結果，最大差異約 1.15×10⁻⁷。
- 瀏覽器於 1280×720、2560×1440 載入 V1.5 素材；確認三區題目與鍵盤版面，三人分別輸入正確答案後各自獲得 JET Level 1。

## 實機界線

測試瀏覽器未提供 WebGL2，瀏覽器 UI 檢查使用 2D 相容模式；3D 著色器、動畫與場景另用上述 OpenGL ES 3 核對。2D 相容模式的地面人物與特效較簡化。

未在真正的 Surface Pro 8、IFP8653 或 AirSync Touchback 上量測；不把 30 FPS 檢查影片或 60 Hz 程式取樣當成實機效能，也不宣稱固定 60 FPS 或實體觸控硬體問題已完全排除。
