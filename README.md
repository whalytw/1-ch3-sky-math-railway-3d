# 天空函數鐵道 3D — 噴射競速 V1.3

2026-10-25 更新。完整版本，可直接覆蓋原專案；原有八類題庫、答案與難度保留，並補齊參數題缺少的公式。

## 使用方式

解壓縮後，將資料夾內全部檔案上傳或覆蓋原 GitHub Pages 專案。請連同整個 `src/` 一起更新，尤其包含 `scene-worker.js`、`effects.js` 以及本次新增的 `decorations.js`、`background.js`、`sprites.js`、`encounters.js`，不要只換 index.html。上傳後按 Ctrl+F5，確認頁首為「三人競速 V1.3」。

本機測試：在本資料夾執行 `python -m http.server 8000`（Windows 亦可用 `py -m http.server 8000`），以 Chrome／Edge 開啟 `http://localhost:8000`。請透過 HTTP 伺服器或 GitHub Pages 開啟，直接雙擊 index.html 可能被瀏覽器限制。

不需安裝 npm 執行套件、下載大型 3D 引擎、模型、音效或使用外部 CDN。

## V1.3：地形修復與鏡頭內伴飛

- 軌道兩側改為完整平整路肩，地面網格沿路肩邊界取樣並加密。貼地仍依每場隨機 50%～85% 設定；起終點維持貼地廣場。
- 約束相鄰軌道橫向淨空，減少緊鄰軌道的巨大高度差，三條路線各自保持 5 公里；避免側坡穿過鋼軌、枕木或形成擋住鏡頭的高牆。上坡鏡頭也會較自然地跟隨坡度。
- 每位沿途觀眾獨立按實際三角形地面網格定位，歡呼時雙腳留在地面上；起終點觀眾也使用腳下淨空檢查。
- 移除地形中舊的固定葉片風車。動態風車面向軌道，葉片依遊戲時間連續旋轉；暫停時停止、繼續後接續轉動。飛機螺旋槳同樣持續旋轉。
- 飛行點綴新增近景伴飛：依玩家目前的鏡頭、題目卡、數字鍵盤、儀表與角色位置尋找空白舞台，再決定大小、距離與角度。不是只把物件放在地圖遠方。
- 鳥群、鯨魚、火龍、巫婆、披風英雄、雙翼飛機、彩蝶、飛船、紙飛機、雲朵綿羊、機器人、水母、風箏可伴飛。每次有 16～19 秒的伴飛時窗，加入緩慢升降、左右擺動、轉向和淡入淡出。依空間與地形安全判定呈現，避免穿過山坡、主角、礦車或遮住答題介面。
- 保留四段密度、25 個細部開關、題庫、加速機制、獨立解題紀錄與多人即時觸控。

驗證新增 39,690 組實際地面網格的鋼軌／路肩淨空、17,248 組觀眾腳下檢查，以及多種地形與鏡頭下的伴飛構圖、安全距離、持續搖擺及風車旋轉。3D 場景另以實際 OpenGL ES 3 渲染核對；實機效能仍請在 Surface Pro 8 確認。

## 前版保留的十一項改進

1. **題目參數補齊**：拋物線開口題顯示「待調整軌道：y=ax²」和目標函數；水平／鉛直平移、多參數、直線與配方題也顯示含參數公式。答案與原本難度不變。
2. **三區明確分隔**：分隔線加粗為 8 CSS 像素、深色高對比並加亮邊；三人獨立操作與滿版畫面保留。
3. **原創圓潤探險家**：重新製作平滑橢圓臉、清楚的眼睛／眉毛／鼻子、微笑、腮紅、圓頂礦工帽、領巾與吊帶工作服。保留完整雙腿、跳躍與揮手。未使用 Minecraft 人物、皮膚或美術資產。
4. **貼地與高架交替**：每場依 seed 隨機決定 50%～85% 弧長貼地，沿途穿插橋梁和峽谷高架。起點、終點與終點滑行區貼地，觀眾與礦車處於同一地面高度。
5. **畫質名稱**：自動選項改為「自動畫質」。
6. **可調動態點綴**：密度四段「豐富／中等／少量／關閉」。設定頁最下方以 25 個小型方框獨立開關，提供全開／全關。模型與貼圖預先快取，不在每幀建立；依距離、畫質與密度限制同時數量。
7. **豐富地貌**：河流、橋面與欄杆、可通過的山洞、湖泊、巨石與層狀峽谷。三條軌道與場景仍共用世界座標。
8. **遠處背景貼圖**：可關閉，提供每場隨機、晚霞與落日、雄偉群山、富士山、湖畔城堡、極光星空、海上群島、沙漠古城、星環行星、雲端宮殿。貼圖由程式生成並快取，隨朝向偏移、兩個風景區平順混合，不需下載外部圖片。
9. **背板修復**：礦車改成分離的地板、前後板和側板，移除原本相互穿插的背面；號碼牌與背板保持明確厚度間距，降低重疊表面的閃爍。
10. **座號下拉選單**：預設 1～30 號，教師可調最大座號為 3～99。三人不得同號；所選座號以立體數字直接顯示在礦車背板，無須手寫或額外輸入。
11. **累計秒數成績**：預設顯示如「98.9 秒」，統一設定可切回「01:38.9」。碼表、完賽卡與個人紀錄同步切換；CSV 同時保留原始完賽秒數與目前格式的顯示欄。

### 25 種動態點綴

原指定 15 種：雪地飄雪、火山噴射火球、鳥群、熱氣球、沿途加油人群、旋轉風車、飛翔鯨魚、巨大火龍、掃把巫婆、原創披風飛行英雄、雙翼螺旋槳飛機、風滾草、三種巨型恐龍、陣雨、雨後彩虹。

新增 10 種：螢火蟲光舞、彩蝶花群、蒸汽飛船、紙飛機編隊、浮空花園、流星光尾、雲朵綿羊、噴射郵差機器人、發光天空水母、彩色風箏列隊。

飄雪限雪地、火球限火山；火球從路邊火山口沿弧線噴出。雨和雨後彩虹交替時段出現。每個動態物件使用涵蓋完整模型與動畫的保守包圍範圍，逐幀排除三位主角及礦車的空間；風滾草只在三台車距離該橫越路段均大於安全距離時滾過軌道。起終點迎賓觀眾屬固定場景，關閉沿途人群或點綴密度仍保留。

## 新加速規則

| 狀態 | 上限速度 | 速度變化 |
|---|---:|---|
| 無加速段 | 60 km/h | 每秒減少 5 km/h，最低回到 60 |
| Level 1：1 段尚未用完 | 75 km/h | 由當時速度在 1.5 秒內升至上限 |
| Level 2：2 段尚未用完 | 90 km/h | 升級後 1.5 秒內升至上限 |
| Level 3：3 段以上尚未用完 | 100 km/h | 升級後 1.5 秒內升至上限 |

降級時若當前速度高於新級別上限，依每秒 5 km/h 逐漸下降，不瞬間跳速。加速耗盡但速度尚未降回 60 時又答對，引擎會再次彈出；若當時速度已高於新上限，同樣依每秒 5 km/h 降至該上限。

起步仍保留原本 0→60 km/h 的 5 秒加速；衝線前、起步完成後，速度不會低於 60。衝線後則依 15 秒停車規則減至 0。

### 依本次指定的例子

| 遊戲時間 | 內部排程 | 當下引擎 |
|---|---|---|
| 25.1 秒答對，獲得 10 秒 | 第一段：25.1～35.1 | 立即 Level 1；26.6 秒達 75 km/h |
| 30.1 秒又答對，獲得 20 秒 | 第二段接在後面：35.1～55.1 | 第一段尚未用完，立即 Level 2；31.6 秒達 90 km/h |
| 35.1 秒 | 第一段耗盡，只剩第二段 | 降至 Level 1，速度從 90 以每秒 5 km/h 降回 75 |
| 55.1 秒 | 第二段耗盡 | 引擎收起，速度以每秒 5 km/h 降回 60 |

遊戲畫面只顯示目前 Level 與總剩餘加速秒數，不顯示這些內部排程時間。每次獲得的段落與時間保存在該場內部紀錄中。

## 原本保留的規則

- 三人統一教師設定，三秒倒數後一起發車，GO 開始計時。
- 同一張隨機地圖，三條軌道實際弧長各 5 公里；前後半段各 2.5 公里，共用兩種不同主題風景。
- 風景共八種：森林、丘陵、雪地、火山、田園、沙漠、鄉下、湖畔。
- 各區自己的大亮點與百分比、另外兩車的小亮點、碼表、速度、加速秒數。
- GO 後 8 秒出第一題；作答時持續行車。答對、答錯、逾時都固定等待 5 秒出下一題。
- 每題一張求救卡，立即扣 10 秒，最低扣到 0；扣到 0 就立即逾時。
- 題目使用黑底半透明卡片，數字鍵盤在右下，角色保留在左下。長題可在卡片內捲動。
- 數字鍵按下立即輸入；± 切正負、⌫ 刪除、→ 換欄、✓ 送出。選擇題先選再確認。
- 三人全數完賽且滑行停妥後，開始下一組。各玩家的正式碼表在自己衝線當下停止。
- 教師設定、玩法與切換背景分頁仍會全場暫停；自己的解題紀錄不會。

## 題庫、成績與觸控

原題庫涵蓋對稱／中點、函數值、直線斜率截距、拋物線平移、配方、判別式、二次函數極值、營收與面積最佳化。預設前四類、每題 45 秒，可選 10～180 秒或依題型預設計時。啟用題型按順序輪替，直到各自完賽。

設定與完賽紀錄保存在同一瀏覽器 localStorage，最多 200 場，可在統一設定匯出 CSV；不同電腦不自動同步。比賽中更改難度及秒數影響下一場；音效、畫質、動態景物、遠景與時間顯示即時生效；最大座號在準備下一場時套用。

三人輸入維持 Pointer Events、依 pointerId 獨立處理、後續 click 去重、不以 isPrimary 排除其他學生。數字鍵至少 44 CSS 像素，不在每次輸入時重建鍵盤。統一設定保留觸控接收計數，可比較三人同按與 AirSync／有線觸控回傳的差異。

## 效能與驗證範圍

以 Surface Pro 8 的輕量低多邊形場景為目標：單一 WebGL2 context、三個 viewport、共用 GPU 緩衝、快取頂點狀態、背景地形產生、距離裁切、預載與快取淘汰。遠景僅使用兩張 1536×512 的程式貼圖；沒有即時陰影、全畫面動態模糊或外部 3D 引擎。預設目標約 60 FPS；若仍不順，可選省電畫質。

已完成：

- 原題庫 7,200 題及常數 ±1 顯示回歸，另驗證 900 組參數題的參數公式。
- 18,036 組貼地與淨空檢查、25 種模型的包圍範圍、四段密度、獨立開關、座號與時間格式設定遷移。
- 指定的 25.1／30.1 秒排程例子、三級上限、1.5 秒加速、5 km/h/s 消退、引擎彈出各階段、再次點火與完整比賽。
- 15 秒衝線滑行、跨線時間固定、滑行距離、600 公尺延伸與兩秒正面運鏡。
- 20 種地圖種子、3,060 組路線／鏡頭取樣、連續轉向、角色完整下半身與構圖。
- 三個重疊觸點、非主要觸點、快速交錯按鍵、長按、取消與 click 去重。

- 瀏覽器內自己的紀錄面板，以及紀錄開啟時其他兩區能繼續倒數、作答、加速。

可用 `npm test` 重跑隨附的 Node.js 測試，不需安裝套件。

測試瀏覽器未提供 WebGL2，瀏覽器操作使用 2D 相容模式；3D 模型另用 OpenGL ES 3 離屏驗證。2D 相容模式的造型與特效較簡化。尚未在真正的 Surface Pro 8／IFP8653／AirSync 連線上測得實際幀率與多點觸控表現，因此不保證任何環境固定達到 60 FPS。網頁也無法補回硬體或 Touchback 未傳入瀏覽器的觸點。
