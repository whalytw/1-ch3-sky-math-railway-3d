# 天空函數鐵道 3D — 陰影與自然飛行 V1.6

2026-10-27 更新。完整可覆蓋版本；保留題庫、答案、難度、三級加速與三人獨立觸控。

## 更新與啟動

解壓縮後，將資料夾內的 `index.html`、`styles.css`、整個 `src/` 與 `assets/` 一起覆蓋原 GitHub Pages 專案。新增的 `flight.js`、`lighting.js`、`shadows.js` 和所有圖片都需要上傳。完成後按 Ctrl+F5，確認頁首顯示「三人競速 V1.6」。圖片載入完畢才會開放出發。

本機可執行 `python -m http.server 8000`（Windows 可用 `py -m http.server 8000`），以 Chrome／Edge 開啟 `http://localhost:8000`。請透過 HTTP 或 GitHub Pages 開啟，避免直接雙擊 HTML 的模組載入限制。遊戲沒有外部 CDN、執行期套件或大型 3D 引擎依賴。

## 這版的變化

- 礦車有貼地接觸陰影；近處飛行物的陰影隨位置、高度與翼姿移動，投在實際地面或橋面。高處的陰影較淡、較散。夜間陰影減淡，獨角獸、水母與低空飛碟有淡淡地面光暈。
- 教師設定新增陰影「關閉／標準／細緻」，預設標準；三區共用陰影資料，每秒最多更新 30 次，畫面仍依原本畫質設定更新。
- 快速角色從後方追上、短暫伴飛、再加速離去，或沿世界中的橫越路線飛過。三位玩家看到的是同一隻角色，不為每個鏡頭複製分身。
- 鳥、火龍、英雄、女巫、飛機、機器人、鯨魚、飛船與獨角獸使用背面／側面／正面／仰視四張方向圖，依真實航向選擇。紙飛機改為有摺線的立體模型，機頭直接對準移動方向。
- 紙飛機與風箏每次各一個；鳥群、蝴蝶才有錯開位置與拍翼時間的小群。風箏有繫到路邊人物的垂線；水母、氣球、鯨魚、綿羊在路段中慢慢飄動，礦車會經過它們。
- 飛船每場有 40% 機率從遠方出現，緩緩向右移動；礦車接近時自然放大，有機會從下方經過。
- 遠方浮島改為巨樹、層層古城、拱廊、垂根與瀑布的天空古城。固定在終點外兩萬多公尺，隨前進稍微放大，永遠無法到達。
- 新增日夜皆可遇到的立體飛碟：斜向接近、停懸觀察、斜上加速離去；外緣與底部燈光在夜間仍可辨識。
- 夜景新增泛白光的有翼獨角獸、遠處人造衛星，並將流星改為遠景的單顆流星／錯開時間的流星雨。獨角獸是稀有事件，僅在夜景且該場抽中時出現。

設定頁共有 28 種點綴的獨立開關，保留豐富／中等／少量／關閉四段密度。夜景對應「極光星空」或「星環行星」；每場隨機背景也可能選中。改變背景不會改動題庫。

全部點綴的行為對照見 `docs/DECORATION-AUDIT.md`。實際渲染檢查圖為 `docs/render-day-v1.6.png`、`render-night-v1.6.png`、`render-bridge-v1.6.png`，使用固定測試位置展示效果，未疊上題目介面，也不代表正式遊戲每次都同時出現這些元素。

## 新加速規則

| 狀態 | 上限速度 | 速度變化 |
|---|---:|---|
| 無加速段 | 60 km/h | 每秒減少 5 km/h，最低回到 60 |
| Level 1：1 段尚未用完 | 75 km/h | 由當時速度在 1.5 秒內升至上限 |
| Level 2：2 段尚未用完 | 90 km/h | 升級後 1.5 秒內升至上限 |
| Level 3：3 段以上尚未用完 | 100 km/h | 升級後 1.5 秒內升至上限 |

降級時若當前速度高於新級別上限，依每秒 5 km/h 逐漸下降，不瞬間跳速。加速耗盡但速度尚未降回 60 時又答對，引擎會再次彈出；若當時速度已高於新上限，同樣依每秒 5 km/h 降至該上限。

起步仍保留原本 0→60 km/h 的 5 秒加速；衝線前、起步完成後，速度不會低於 60。衝線後則依 15 秒停車規則減至 0。

### 依本次指定的例子

| 遊戲時間 | 內部排程 | 當下引擎 |
|---|---|---|
| 25.1 秒答對，獲得 10 秒 | 第一段：25.1～35.1 | 立即 Level 1；26.6 秒達 75 km/h |
| 30.1 秒又答對，獲得 20 秒 | 第二段接在後面：35.1～55.1 | 第一段尚未用完，立即 Level 2；31.6 秒達 90 km/h |
| 35.1 秒 | 第一段耗盡，只剩第二段 | 降至 Level 1，速度從 90 以每秒 5 km/h 降回 75 |
| 55.1 秒 | 第二段耗盡 | 引擎收起，速度以每秒 5 km/h 降回 60 |

遊戲畫面只顯示目前 Level 與總剩餘加速秒數，不顯示這些內部排程時間。每次獲得的段落與時間保存在該場內部紀錄中。

## 原本保留的規則

- 三人統一教師設定，三秒倒數後一起發車，GO 開始計時。
- 同一張隨機地圖，三條軌道實際弧長各 5 公里；前後半段各 2.5 公里，共用兩種不同主題風景。
- 風景共八種：森林、丘陵、雪地、火山、田園、沙漠、鄉下、湖畔。
- 各區自己的大亮點與百分比、另外兩車的小亮點、碼表、速度、加速秒數。
- GO 後 8 秒出第一題；作答時持續行車。答對、答錯、逾時都固定等待 5 秒出下一題。
- 每題一張求救卡，立即扣 10 秒，最低扣到 0；扣到 0 就立即逾時。
- 題目使用黑底半透明卡片，數字鍵盤在右下，角色保留在左下。長題可在卡片內捲動。
- 數字鍵按下立即輸入；± 切正負、⌫ 刪除、→ 換欄、✓ 送出。選擇題先選再確認。
- 三人全數完賽且滑行停妥後，開始下一組。各玩家的正式碼表在自己衝線當下停止。
- 教師設定、玩法與切換背景分頁仍會全場暫停；自己的解題紀錄不會。

## 題庫、成績與觸控

原題庫涵蓋對稱／中點、函數值、直線斜率截距、拋物線平移、配方、判別式、二次函數極值、營收與面積最佳化。預設前四類、每題 45 秒，可選 10～180 秒或依題型預設計時。啟用題型按順序輪替，直到各自完賽。

設定與完賽紀錄保存在同一瀏覽器 localStorage，最多 200 場，可在統一設定匯出 CSV；不同電腦不自動同步。比賽中更改難度及秒數影響下一場；音效、畫質、動態景物、遠景與時間顯示即時生效；最大座號在準備下一場時套用。

三人輸入維持 Pointer Events、依 pointerId 獨立處理、後續 click 去重、不以 isPrimary 排除其他學生。數字鍵至少 44 CSS 像素，不在每次輸入時重建鍵盤。統一設定保留觸控接收計數，可比較三人同按與 AirSync／有線觸控回傳的差異。

## 效能與驗證範圍

`npm test` 可重跑 12 組 Node.js 測試，不需安裝 npm 套件：包括題庫、賽程、地形、三人觸控、渲染狀態、背景 Worker、設定、點綴、飛行朝向、動畫與陰影。細節見 `docs/VALIDATION.md`。

這版另以真正的 OpenGL ES 3 管線重播遊戲渲染器的日景、夜景與橋梁場景，並核對 CPU／GPU 動畫變形。這是離屏渲染驗證；本輪未在可操作的瀏覽器或真正的 Surface Pro 8／IFP8653／AirSync Touchback 上測試。2D 相容模式也輸出核對了三種場景，但人物、橋梁與光影細節較簡化。

飛行插畫仍是世界座標中的可變形透明網格，並非完整立體角色；方向切換使用對應圖片。紙飛機與飛碟則使用真正的立體幾何。陰影是貼合接收面的柔邊近似投影，不是逐像素輪廓陰影或昂貴的全場景 shadow map。未知教室設備的實際幀率，不宣稱固定 60 FPS；可調低陰影與點綴密度。
